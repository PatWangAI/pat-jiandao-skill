# 通用术语表

没有讲稿时，字幕的专有名词靠术语表改（scripts/terms.py）。每个词一行，以“- ”开头（说明文字别用“- ”开头，会被当成词）：
1. 写成“正确写法：听错的写法、听错的写法”，转写稿里出现听错的写法（不分大小写、不管空格），整段换成正确写法；
2. 只写正确写法，就只改大小写和空格（比如 github → GitHub）。

不看上下文就改，所以每处都列进修字表，看过再用；改错了就改这里。一条视频自己的词（店名、产品名、人名），
写进那条视频文件夹里的 术语表.md，由用户给。
