# Pat 剪刀 · AI 剪辑 skill

中文 | [English](README.en.md)

一句话把手机录的中文口播剪成带中英字幕的成片：横屏讲解按讲稿一句配一个画面，带左下角圆形人脸小窗；竖屏口播整片人脸。文科生 Pat 的文具盒 skills · 第 1 件。

Pat 剪刀是一个给 AI 编程助手用的剪辑 skill（skill：一份写给 AI 助手的操作说明，加上它调用的脚本）。手机录一条中文口播，在 Claude Code 或 TRAE 里说一句“剪成成片”，它会（中间停两次，请你确认删除方案、听过粗剪）：删掉语气词、说断和重说的地方，压掉长停顿，剪完再听一遍复核，配上中英字幕；有讲稿的话按讲稿逐句找素材、配画面，加转场和背景音乐，出 16:9 或竖屏成片。

## 实测的数字（都带着条件）

- 删得准不准：在 Claude Code 里另开没看过答案的助手，只给转写稿和这个 skill，判作者已经发布的 3 期口播，要删的 20 处找对 19 处，另外多删了 1 处。
- 一条 46 秒、没有讲稿的测试片，用 Claude Code 剪：误删、漏删、切到字、爆音、字幕错字都是 0。用 TRAE（中国版，模型 Seed-2.1-Pro）剪同一条，作者照步骤给它发指令（每一步跑哪条命令写清楚），它漏删了 1 处（那个只说两个字的半句）、字幕有一行断错，都在确认的那两步改过来了。
- 安装：在一台已经装好 Homebrew、Xcode 命令行工具、uv、ffmpeg 的 Mac 上实测两次：新账户照安装说明装好、剪出第一条粗剪，全程约 15 分钟；空的主文件夹装到环境检查通过，3 分半。时间主要看网速（装 Python 环境 1 分半到 8 分多钟，下 2.1 GB 的转写模型约 2 分钟），装完约占 4.3 GB。Homebrew 这几样没装的，时间另算。
- 转写在你自己的电脑上跑（FunASR），不用另买语音接口。

## 能做什么

- 删语气词（嗯、啊、呃、口头禅）、说断和重说，只留最后完整的那一遍；压长停顿。说一句“节奏紧一点”，剪口只留约 0.15 秒。
- 剪完把声音再转写一遍，和方案逐字对，多删、少删自动挪刀；接缝做一段试听给你听。
- 中英双语字幕，每行不超过 16 个字；另出 .srt 字幕文件。
- 有讲稿时按讲稿逐句找素材：截来源网页并画框标出那句话、搜图库（Pixabay），一句一个画面，加推拉等动效。16:9 成片每句都要配一个画面（自动拿的或你自己给的）；不想配画面，就出竖屏整片人脸，或者直接用粗剪加 .srt 字幕。
- 左下角圆形人脸小窗，能跟着脸走；只录声音不露脸也能剪。
- 转场、背景音乐（几首轮流放）、响度统一、成片自检。
- 竖屏 1080×1920（默认整片人脸，字幕躲开平台界面）。
- 没有讲稿也能剪。
- 把粗剪导成剪映草稿，在剪映里接着改（非官方功能，见下面“要知道的”）。

## 要什么

- Apple 芯片（M1 起）的 Mac。Intel 的 Mac 没试过，Windows 不支持（小窗跟脸用的是苹果系统自带的人脸识别）。
- 空间：装好约占 4.3 GB；剪片还要放中间文件，环境检查要求至少剩 10 GB。
- 一个能在终端跑命令、认得 SKILL.md、能看图的 AI 编程助手：
  - Claude Code：实测过全部流程（16:9 和竖屏成片、只录声音、有讲稿和没讲稿）。要有 Claude 的订阅或接口额度。作者的原片都是手机竖拍的，横拍的原片没测过。
  - TRAE（中国版）：实测过竖屏口播、没讲稿、从原片剪到成片，作者照步骤给它发指令；16:9 成片、只说一句“剪成成片”让它自己走完，都没在 TRAE 里测过。仓库里的 `.trae/skills/jianji` 放的是同一份 skill 的副本。
  - 别的编程助手：应该能用，没实测过。
- 可选：Google Chrome（找素材时截网页）、Pixabay 的免费密钥（找图库素材，自己申请，不要分享给别人）、剪映专业版（导草稿）。
- 网络：装 Homebrew、uv 下载 Python 都要连 GitHub，国内网络可能连不上、要代理；换镜像的办法作者没测过。

## 安装

先把代码拿到手：在这个页面点绿色的 Code → Download ZIP，解压出来的文件夹改名叫 pat-jiandao-skill，放进你的主文件夹（访达左边带小房子图标的那个）。会用 git 的也可以 `git clone`。

然后在 Claude Code 或 TRAE 里打开这个文件夹，把下面这段贴给它（这个办法作者没在一台全新的电脑上完整试过，卡住了就照安装说明一步步来）：

```
请照 docs/安装说明.md 帮我把 Pat 剪刀（AI 剪辑 skill）装好：从“一步步装”的第 1 步做起，每条命令先说要做什么再运行；要输电脑密码、要我同意下载大文件（转写模型 2.1 GB）的地方停下来告诉我，由我自己操作。全部装完跑 uv run python scripts/doctor.py，把还缺的和怎么装列给我。
```

想自己一步步装，看 [docs/安装说明.md](docs/安装说明.md)。装完跑环境检查，它会告诉你还缺什么、怎么装：

```bash
uv run python scripts/doctor.py
```

## 怎么用

录之前，iPhone 先在 设置 → 相机 → 录制视频 里关掉“HDR 视频”，不然预处理会停下请你重录。

把原片放进“下载”文件夹，在助手里说“剪成成片”。没讲稿、要竖屏、只用声音、节奏紧一点，说一声就行。有讲稿的话，照 [docs/讲稿样例.md](docs/讲稿样例.md) 写成一个 .md 文件（要有“## 讲稿全文”一节，句子按 1. 2. 3. 编号），Word、纯文本的先让助手照样例改一份。

用 TRAE 的，可以这样起头：

```
用这个项目里的 jianji 技能（.trae/skills/jianji/SKILL.md，先从头读完），把“下载”文件夹里最新的那条视频剪成成片。没有讲稿，要竖屏。第 5 步删除方案和第 8 步粗剪，等我回“可以”再往下。
```

中间有两步一定要你自己看：

1. **删除方案**：它把要删的每一处列出来（原话和时间），你说“可以”才剪。换了模型，判断会有差别。
2. **粗剪**：听一遍粗剪和接缝试听，字幕看一遍，没问题再往下配素材、出成片。

## 要知道的

- 隐私：转写在你的电脑上做，原片和素材也只在你的电脑上处理；但你用的 AI 助手会读转写稿、方案和一些截图、截帧，这些会发到助手的服务器，按你和助手之间的条款处理。
- 素材的版权：skill 会截网页、下图库素材，并写一份 来源清单.md。视频里用的素材合不合适，由你自己判断；发布前看一遍来源清单。遇到网站拦截程序访问，它不绕过。
- 剪映草稿：靠开源库 pyJianYingDraft 写成，非剪映官方功能，剪映升级后可能打不开。只测过剪映专业版 9.6.0（Mac）、竖屏。现在只导粗剪的内容（画面段、原声、字幕），配的素材、转场、背景音乐还不进草稿。
- AI 会判错：删除方案和粗剪两步认真看。
- 连着说的语气词（“哎救不回来”这种，字和字之间没有停顿）切不干净，硬删会留一点尾巴。方案里会把它们单列成“连读待定”，默认不删；你选了删，粗剪那步要听一下那个接缝。
- 这是个人维护的项目，回复可能慢。提问题请用 issue 模板，先贴环境检查的输出。

## 致谢

这个 skill 的代码是自己写的，下面几个开源项目的做法给了我们思路：

- [ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill)（MIT）：环境检查逐项报“有、缺、可选缺”。
- [video-use](https://github.com/browser-use/video-use)（MIT）：按停顿分段的转写阅读稿；“贴给助手就能装”的安装说明。
- [chengfeng-videocut-skills](https://github.com/Agentchengfeng/chengfeng-videocut-skills)（Apache-2.0）：没有讲稿时的五轮扫描、删词汇总表和重复句子表（表头“说了几遍、保了哪遍、删了哪几遍、风险”照用了它的写法）、删完自己通读一遍、按术语表改字。
- [OpenMontage](https://github.com/calesthio/OpenMontage)：用一份步骤清单管整个流程的想法。

转写用 [FunASR](https://github.com/modelscope/FunASR) 的模型，剪辑用 [FFmpeg](https://ffmpeg.org/)，字幕字体是 Adobe 的[思源黑体](https://github.com/adobe-fonts/source-han-sans)，剪映草稿用 [pyJianYingDraft](https://github.com/GuanYixuan/pyJianYingDraft)。
