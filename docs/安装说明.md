# Pat 剪刀（AI 剪辑 skill）安装说明

照着从上往下做，装到能剪出一条粗剪。只支持 Mac，在 Apple 芯片（M1 起）、8 GB 内存、macOS 26 上装过；Intel 的 Mac 没试过。

作者实测两次（一次在同一台 Mac 的另一个普通账户里，一次在一个空的主文件夹里），从第 4 步装到环境检查通过，分别约 15 分钟和 3 分半，主要看网速；装完约占 4.3 GB。那台 Mac 上 Xcode 命令行工具、Homebrew、uv、ffmpeg-full 早就装好了，所以第 1—3 步的时间没算在里面。

转写用本机的 FunASR 模型、剪辑用 FFmpeg，这两样不要密钥、不花钱。要花钱的是你用的 AI 助手：Claude Code 要有 Claude 的订阅或接口额度，TRAE 有免费额度。“找素材”时搜图库要一个免费的 Pixabay 密钥，不用这一步可以不要。

## 先准备好

- 空间：约 6 GB。Python 环境约 1 GB（另有约 1 GB 下载缓存），转写模型 2.1 GB，FFmpeg 和 Homebrew 的东西约 1 GB；剪一条几分钟的片子，中间文件还要几个 GB。
- 网络：要连得上 GitHub（Homebrew、uv 下 Python）、PyPI（Python 的库）、ModelScope（转写模型）。
- AI 助手：Claude Code（桌面版或命令行版）或 TRAE，要能登录。别的编程助手只要认得 SKILL.md、能在终端跑命令、能看图，应该也能用，没实测过。

## 先把代码拿到手

在仓库的 GitHub 页面点 Code → Download ZIP，解压后把文件夹改名叫 pat-jiandao-skill，放在你自己的文件夹里（比如 ~/projects/pat-jiandao-skill）。装好 git 的也可以用下面第 4 步的 `git clone`。

## 懒办法：交给助手装

在 Claude Code 或 TRAE 里打开仓库文件夹，把下面这段贴给它：

> 请照 docs/安装说明.md 帮我把 Pat 剪刀（AI 剪辑 skill）装好：从“一步步装”的第 1 步做起，每条命令先说要做什么再运行；要输电脑密码、要我同意下载大文件（转写模型 2.1 GB）的地方停下来告诉我，由我自己操作。全部装完跑 `uv run python scripts/doctor.py`，把还缺的和怎么装列给我。

要输密码的只有第 1、2 步（装 Xcode 命令行工具和 Homebrew），这两步要你自己在终端里做。

## 一步步装

以下命令都在“终端”里运行。

1. 装 Xcode 命令行工具（带 git 和 swift；装过的会提示已经装了）：

   ```bash
   xcode-select --install
   ```

2. 装 Homebrew（已经有 `brew` 命令的跳过；要输一次电脑密码，账户要是管理员）：

   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

   装完照它最后打印的“Next steps”把 brew 加进 PATH，关掉终端再开一个。

   这台 Mac 上已经有别的账户装过 Homebrew（有 /opt/homebrew 这个文件夹），自己的账户里却没有 `brew` 命令时：不要再装一遍，把它加进自己的 PATH 就行（每个账户都要做一次）：

   ```bash
   echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile && eval "$(/opt/homebrew/bin/brew shellenv)"
   ```

3. 装 uv（管 Python 环境）和 ffmpeg-full（带 libass 的 FFmpeg；Homebrew 默认的 `ffmpeg` 不带 libass，烧不了字幕）：

   ```bash
   brew install uv ffmpeg-full
   ```

   ffmpeg-full 不挂到 PATH 上，程序按 /opt/homebrew/opt/ffmpeg-full/bin/ffmpeg 找它（写在 config.yaml）。

   Homebrew 是别的账户装的、自己的账户又不是管理员时，`brew install` 装不了新东西：它会报“/opt/homebrew/Cellar is not writable”，还建议跑 `sudo chown -R <你的账户> /opt/homebrew…`。**不要照它说的做**，那会把 Homebrew 改归你的账户，装它的那个账户就用不了了（作者在测试账户里试出来的）。先看装没装：

   ```bash
   ls /opt/homebrew/bin/uv /opt/homebrew/opt/ffmpeg-full/bin/ffmpeg
   ```

   两个都列出来了就是装好了，跳到第 4 步；缺哪个，请装 Homebrew 的那个账户帮忙跑一次 `brew install uv ffmpeg-full`。

4. 取代码（已经下了 ZIP 的跳过 git clone），放在自己的文件夹里（比如 ~/projects/pat-jiandao-skill），然后进到这个文件夹：

   ```bash
   git clone https://github.com/PatWangAI/pat-jiandao-skill.git ~/projects/pat-jiandao-skill
   ```

   ```bash
   cd ~/projects/pat-jiandao-skill
   ```


5. 装 Python 环境（uv 会自己下 Python 3.12 和固定版本的库，torch 比较大；作者实测 1 分半到 8 分多钟，看网速；不动系统自带的 Python）：

   ```bash
   uv sync
   ```

6. 下转写模型（三个 FunASR 模型共约 2.1 GB，从 ModelScope 下到 ~/.cache/modelscope/；加上这个变量是 8 个连接一起下，不加只有一个，很慢）：

   ```bash
   MODELSCOPE_DOWNLOAD_PARALLELS=8 uv run python scripts/download_models.py
   ```

7. 本机设置（可以跳过，跳过就用默认值：视频放 ~/视频制作，原片从“下载”文件夹找）：

   ```bash
   cp config.local.example.yaml config.local.yaml
   ```

   再打开 config.local.yaml，照里面的说明改视频放哪、去哪找原片和讲稿。这个文件只在你的电脑上，不进仓库。

8. 环境检查：

   ```bash
   uv run python scripts/doctor.py
   ```

   逐项报“有、缺、可选缺”，缺的会写怎么装。最后一行是“必需的都齐了，可以剪。”就装好了。还没装好 Python 环境时，可以先用 `python3 scripts/doctor.py` 看缺什么。

## 可选的

- 找素材时截网页：要装 Google Chrome（程序用它的无头模式截图，不另下浏览器）。
- 图库找图：在 pixabay.com 登录后，打开 API 文档页取免费密钥，写进 ~/.zshrc（`export PIXABAY_API_KEY=…`），不要贴进聊天。
- 小窗跟着脸走：要 swift，第 1 步的 Xcode 命令行工具里就有。

## 剪第一条

1. 在 Claude Code 或 TRAE 里打开仓库文件夹。
2. 把原片放进“下载”文件夹（或 config.local.yaml 里 video_dirs 写的文件夹），说“剪成成片”，或者输入 /jianji。也可以直接给原片路径。
3. 它会先列出找到的原片和讲稿让你确认，再转写、出删除方案等你确认，然后剪出粗剪（粗剪.mp4）。

视频文件夹不在 ~/视频制作 时，skill 往里写文件会多问几次权限，点允许就行。

## 出问题时

- 先跑 `uv run python scripts/doctor.py`，看缺什么。
- `uv sync` 卡住或报网络错：多半是连不上 PyPI 或 GitHub，换个网络再试。
- 下模型很慢：确认命令前面带了 `MODELSCOPE_DOWNLOAD_PARALLELS=8`；断了重跑同一条命令，下好的不会重下。
- 烧字幕报错或字体不对：确认装的是 ffmpeg-full，不是 ffmpeg（环境检查里“烧字幕试一行”那项会说选中了哪个字体）。
